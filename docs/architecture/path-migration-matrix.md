## Stable contracts during internal breakage

The matrix permits internal source-path and import breakage only when all repository consumers migrate in the same stage. These remain stable unless another approved product plan says otherwise:

- HTTP paths, OpenAPI behavior, and template/static public URLs;
- Celery registered task names and queued-message compatibility;
- database schema and Alembic revision identifiers;
- systemd unit names and installed service semantics;
- configuration keys/environment variable names and user-maintained live files;
- artifact formats, catalog schemas, and guest workload identifiers;
- the documented first-VM image-download command and its behavior, even when its source path is intentionally migrated;
- release license/source boundary and operator-owned Volatility/dwarf2json policy.
