# Referencia de la API

!!! note "Movido"
    La documentación de API mantenida ahora está en [Visión general de la API](../api/overview.md), [Endpoints de la API](../api/endpoints.md), [Autenticación](../api/authentication.md) y [Errores de la API](../api/errors.md).

AstinusLab proporciona una API REST para orquestar entornos de lab y gestionar artefactos forenses.

**URL base**: `http://<host>:8000/api/v1`

El health check se sirve fuera del prefijo v1 en `GET /health`.
