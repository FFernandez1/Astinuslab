# Referència de l'API

!!! note "Mogut"
    La documentació d'API mantinguda ara és a [Visió general de l'API](../api/overview.md), [Endpoints de l'API](../api/endpoints.md), [Autenticació](../api/authentication.md) i [Errors de l'API](../api/errors.md).

AstinusLab proporciona una API REST per orquestrar entorns de lab i gestionar artefactes forenses.

**URL base**: `http://<host>:8000/api/v1`

El health check se serveix fora del prefix v1 a `GET /health`.
